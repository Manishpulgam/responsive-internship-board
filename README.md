
# InternHub — Responsive Internship Board

A beginner-friendly internship listing website built with
HTML, CSS, and vanilla JavaScript.

## Features

- Responsive mobile, tablet, and desktop layouts
- Search by title, company, location, description, and skills
- Filter internships by domain
- Dynamic internship cards generated from JavaScript data
- Empty and rendering error states
- Accessible labels, keyboard focus, and skip navigation

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)

## Run locally

1. Clone or download this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No build tools or package installation are required.
